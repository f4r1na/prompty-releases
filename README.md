# Prompty releases

Installers and auto-update files for **Prompty for Windows**: select a rough prompt in any app,
press Ctrl + Alt + P, and Prompty rewrites it in place.

- Download the latest installer: [Prompty-Setup.exe](https://github.com/f4r1na/prompty-releases/releases/latest/download/Prompty-Setup.exe)
- Website and account: https://prompty-rosy-chi.vercel.app

This repository holds release files only. The installed app checks `latest.json` here for updates,
and every update is signature-checked before it installs.
